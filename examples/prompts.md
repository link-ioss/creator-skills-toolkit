# 可复制的提示词

把方括号内容替换成真实资料，文件路径使用你的实际路径。

## 30 秒产品介绍

```text
使用 video-spec-builder 帮我做视频需求。
产品：[名称]；受众：[人群]；核心卖点：[一句话]。
发布到抖音与小红书，30 秒，9:16，中文。
已有素材：[图片、录屏、旁白路径]。
请先补齐必要信息并生成 video-spec.md，不要开始渲染。
```

## 60 秒知识讲解

```text
使用 video-spec-builder，把以下知识点整理成 60 秒中文讲解视频：
[知识点与可核对的资料]
面向初学者，核心只讲清楚一个概念。
请标明需要补充出处或素材的位置，不要编造数据。
先给需求和逐镜头安排。
```

## 制作确认后的脚本

```text
使用 hyperframes，读取 [video-spec.md 路径]。
以已确认内容为依据，只询问缺失或冲突的信息。
在新的空目录初始化项目，按当前规范建立 BRIEF.md 和分镜文件。
先展示预览供我查看，再按反馈完成导出。
```

## 修改已有视频

```text
继续当前 HyperFrames 项目，不要重做已经确认的需求。
把 [镜头] 的 [具体元素] 改为 [要求]。
同步受影响的镜头、字幕与音频时间，并重新检查和预览。
```

## 打开看板

```text
使用 neural-creator-dashboard，启动我已有的看板项目 [项目路径]。
打开本地页面，不要重新导入或覆盖我的笔记数据。
```
